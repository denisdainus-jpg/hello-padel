HELLO PADEL RUSSIA — статичный сайт
=====================================

Содержимое
----------
index.html   — весь сайт: текст, стили и скрипты внутри файла
logo.png     — логотип
photos/      — шесть фото Маури Андрини (01, 03, 04, 06, 07, 08)

ВНИМАНИЕ: фото весят 1–2 МБ каждое (всего ~8 МБ). Сайт будет
работать, но с телефона откроется медленно. Лучше сжать их в WebP/JPEG
до 150–300 КБ (ширина ~1000 px) и положить под теми же именами.

Загрузка на TimeWeb
-------------------
1. Панель → Домены → добавить свой домен.
2. Файловый менеджер → папка домена:
   /var/www/<логин>/data/www/<ваш-домен.ru>/
3. Удалите служебный index.html / index.php.
4. Залейте index.html и logo.png в корень (не во вложенную папку).
5. Включите SSL (Let's Encrypt) и редирект на HTTPS.

Сайт не зависит от сторонних серверов: всё, кроме шрифтов
Google Fonts (Unbounded / Manrope), лежит рядом. Без интернета
шрифты подменяются системными, верстка не ломается.

Ссылки на Telegram: поиск по russian_padel_bot в index.html.
